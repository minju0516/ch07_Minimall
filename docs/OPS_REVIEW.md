# OPS_REVIEW — AI 가 만든 운영 산출물 리뷰 (Mission 0·5)

## 1. 점검표 (8항목) — `ai_ops/` 4개 파일을 읽으며 해당 사례를 찾는다
| # | 점검 항목 | 의심 사례(파일 · 위치) |
|---|---|---|
| O1 | 고정 임계값 하나로 판단하는가(평소 대비 · 지속성 없음) | |
| O2 | 한 분(한 번)의 값으로 호출하는가(일시 급증에 취약) | |
| O3 | 전체 평균만 보는가(구간 · 비즈니스 지표 · 결제 실패 · 추천 품질 누락) | |
| O4 | 게이트가 "테스트 통과"만 보는가(건너뜀 · 커버리지 · 비밀 · 취약점 · 모델 품질 누락) | |
| O5 | 카나리를 기존 버전과 비교하지 않고 절대값으로만 보는가(외부 장애 오탐 · 작은 회귀 미탐) | |
| O6 | 재학습을 달력으로 하거나 평균 변화만 보는가(데이터 품질과 드리프트를 구분 못함) | |
| O7 | 모델 승격을 "점수가 올랐나"로만 판단하는가(신뢰구간 · 구간별 · 평가 크기 · 누수 무시) | |
| O8 | 알림에 런북 · 담당 · 복구 확인이 없는가 | |
