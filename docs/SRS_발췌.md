# SRS 발췌 — MiniMall MVP (7강: 운영 관점)

원문: `AI활용_소프트웨어공학_실습_요구사항명세서_SRS_쇼핑몰MVP` (수업용 가상 서비스)

7강은 새 기능을 만드는 실습이 아니라, 5·6강에서 만든 **주문 · 결제 흐름이 운영 환경에서 계속 잘 동작하게 하는 일**을 다룹니다. 운영 대상은 다음과 같습니다.

| 운영 대상 | 근거(SRS 요구) | 운영에서 지켜야 할 것 |
|---|---|---|
| 주문 · 장바구니 API | FR-CART-01, FR-ORD-01, US-07 | 오류율 · 응답 시간 |
| 결제 | FR-PAY-01 · 02 · 05, US-08 | 결제 실패율, 중복 결제 없음(배포 · 롤백 중에도) |
| 취소 · 환불 | FR-ORD-04, FR-PAY-03, US-10 | 환불 실패 시 관리자 확인 가능(알림) |
| 주문 내역 조회 | FR-ORD-03, US-09 | 응답 시간 |
| 추천 모델(7강에서 추가) | 7강 가정 | 추천 클릭률, 모델 버전 · 롤백 |

> **가정(수업용):** 아래 운영 목표(SLO)와 숫자는 이 수업을 위해 추가한 가상의 가정이며 SRS 원문에 있는 것이 아닙니다.
> 5강의 열린 이슈 OI-03(PG 연동)은 '모의 PG'로 정해 두었으므로, 7강에서도 PG 장애는 시뮬레이터가 만든 지표로만 나타납니다.

## 운영 목표(SLO) — `config/slo.json`

| 항목 | 목표 | 비고 |
|---|---|---|
| 가용성 | 99.5% (오류 예산 0.5%) | 30일 기준. 평소 오류율은 약 0.4% 이다 |
